# UserCore API

UserCore API is a simple backend REST API project built using Node.js and Express.js.

## Project Purpose

This project demonstrates:

- Backend API development
- RESTful routing
- GET, POST, PUT, DELETE methods
- JSON request and response handling
- Basic data validation
- HTTP status codes
- Clean folder structure

## Technologies Used

- Node.js
- Express.js
- JavaScript
- Postman
